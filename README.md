# Fintech Review Analytics

Analysis of fintech app user reviews to extract insights on customer satisfaction, sentiment, and product feedback.

## Project Structure

```
fintech-review-analytics/
├── data/raw/           # Raw data files
├── notebooks/          # Jupyter notebooks for exploration and analysis
├── src/                # Source code modules
├── tests/              # Unit tests
└── scripts/            # Utility and pipeline scripts
```

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage

Run notebooks from the `notebooks/` directory or scripts from `scripts/`.
